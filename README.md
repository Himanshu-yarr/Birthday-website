# Birthday Wish Website 🎂✨

A visually interactive birthday wish website built using HTML, React (CDN), Tailwind CSS, and JavaScript.

The project features animations, confetti effects, music playback, scroll-based reveals, premium UI sections, and responsive design to create a modern birthday greeting experience.

---

## 🚀 Features

- Animated Birthday Landing Page
- Interactive Gift Opening Animation
- Canvas Confetti Effects
- Background Music Player
- Scroll Reveal Animations
- Responsive Design
- Premium Glassmorphism UI
- Dynamic Sections & Effects

---

## 🛠️ Tech Stack

- HTML5
- Tailwind CSS
- React (CDN)
- JavaScript
- Font Awesome
